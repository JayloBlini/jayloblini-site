# Site JayloBlini

Site vitrine statique pour la chaîne YouTube JayloBlini.

## Lancer le site

Ouvre `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Fichiers

- `index.html` : structure et contenu du site
- `style.css` : styles, thèmes clair/sombre, mise en page responsive et barre sociale
- `app.js` : personnalisation locale du site, profil, idées, sondages et roulettes de giveaway de démonstration

## À savoir

Les préférences visuelles, le profil et la configuration des roulettes sont enregistrés localement dans le navigateur. La communauté (chat, amis, idées, votes et giveaway) est une maquette locale : les données ne sont pas partagées entre les visiteurs. Le mode créatrice de cette maquette ne remplace pas une authentification côté serveur. Les vidéos et la photo de profil proviennent de YouTube.
